# AirSpaceLocator Bot
**Бот разработан, чтобы обеспечить простой способ получения данных о
местоположении воздушных судов в режиме реального времени.**
- ссылка на бот в Telegram: [AirSpaceLocator](https://t.me/AirLocatorBot).

## Используемые технологии
- Python 3.12.
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный Telegram-фреймворк (Router/FSM).
- [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (async) + [Alembic](https://alembic.sqlalchemy.org/) — ORM и миграции, SQLite через `aiosqlite`.
- [httpx](https://www.python-httpx.org/) — асинхронные запросы к AirLabs и DaData.
- [staticmap](https://github.com/komoot/staticmap) — отрисовка карты по тайлам OSM (без GDAL/GEOS-зависимостей).
- [uv](https://docs.astral.sh/uv/) — управление зависимостями и виртуальным окружением.

## Функционал
- [X] Получение данных с [AirLabs](https://airlabs.co/), с автоматическим переключением на
      [OpenSky Network](https://opensky-network.org/) при недоступности AirLabs.
- [X] Недеструктивная фильтрация полученных данных (по высоте, типу, принадлежности) через
      inline-кнопки — фильтры можно свободно комбинировать и сбрасывать без повторного запроса.
- [X] Быстрый повторный поиск по последнему сохранённому радиусу.
- [X] Отрисовка полученных данных на карте с легендой и подписями воздушных судов.
- [X] Получение подробной информации о конкретном воздушном судне, с фото с
      [planespotters.net](https://www.planespotters.net/) (если найдено) и ссылкой на
      [SKYbrary](https://skybrary.aero/).

## Установка и запуск

### Локально (uv)

- Клонировать репозиторий и перейти в директорию проекта.
- Установить зависимости:
```sh
uv sync
```
- Заполнить `.env` (см. переменные ниже, ориентируйтесь на `.env.template`).
- Применить миграции и запустить бота:
```sh
uv run alembic upgrade head
uv run python -m bot
```

### Docker

```sh
docker compose up --build
```
Миграции (`alembic upgrade head`) применяются автоматически при старте контейнера
(`docker/entrypoint.sh`). Файл базы данных сохраняется в `./data` на хосте.

### Переменные в файле конфигурации (`.env`)

- `BOT_TOKEN` - токен Telegram ([BotFather](https://t.me/botfather)).
- `AIR_LABS_API_KEY` - API токен [AirLabs](https://airlabs.co/).
- `DADATA_TOKEN` - токен [DaData](https://dadata.ru/) (для использования геокодера).
- `DADATA_SECRET_KEY` - секретный ключ [DaData](https://dadata.ru/) (для использования геокодера).

### Тесты и линт
```sh
uv run pytest -q
uv run ruff check .
```

## Интерфейс пользователя
### Основные команды

| Команда    | Описание                                                                                            |
|:-----------|:-----------------------------------------------------------------------------------------------------|
| `/start`   | Запуск бота                                                                                           |
| `/cancel`  | Возвращение в главное меню                                                                            |
| `/help`    | Вывод справки по основным командам                                                                    |
| `/history` | Вывод последних 50 запросов пользователя (значение задается константой `HISTORY_LIMIT` в `bot/constants.py`) |

### Основное меню
| Команда                             | Описание                                                                 |
|:------------------------------------|:---------------------------------------------------------------------------|
| `Изменить местоположение`           | Изменение местоположения                                                 |
| `Получить данные о воздушных судах` | Новый поиск: ввод радиуса (текстом или пресетом) и получение данных      |
| `Повторить последний поиск`         | Повтор поиска с последним использованным радиусом, без повторного ввода  |
| `Подробно о воздушном судне`        | Вывод подробной информации о воздушном судне с фото и ссылкой на SKYbrary |
| `Отрисовать полученные данные`      | Отрисовка полученной информации на карте                                 |

### Меню фильтров (inline-кнопки после поиска)
Открывается сразу после получения данных. Фильтры хранятся отдельно от сохранённой выборки
и применяются только при просмотре — их можно свободно комбинировать, менять и сбрасывать,
не запрашивая данные заново.

| Кнопка               | Описание                                                              |
|:----------------------|:------------------------------------------------------------------------|
| `Высота`              | Выбор диапазона высоты (диапазоны вычисляются из фактических данных) |
| `Тип`                 | Выбор одного или нескольких типов судна                              |
| `Принадлежность`      | Выбор одной или нескольких стран                                     |
| `Показать список`     | Текстовый список судов с учётом текущих фильтров                     |
| `Показать на карте`   | Карта судов с учётом текущих фильтров                                |
| `Сбросить фильтры`    | Сброс всех выбранных критериев                                       |
| `Готово`              | Завершение поиска, возврат в главное меню                            |

### Меню местоположение
| Команда                         | Описание                                                                              |
|:--------------------------------|:--------------------------------------------------------------------------------------|
| `Ввести адрес`                  | Ввести адрес и получить координаты с помощью геодекодера [DaData](https://dadata.ru/) |
| `Ввести координаты`             | Ввод координат вручную                                                                |
| `Отправить свое местоположение` | Ввод местоположению с помощью геолокации                                              |
