# AirSpaceLocator Bot
**Telegram-бот, который показывает воздушные суда, находящиеся рядом с вами,
в режиме реального времени: списком и на карте.**

- Репозиторий: [tromv3/airspace_locator_bot](https://github.com/tromv3/airspace_locator_bot)
- Бот в Telegram: [AirSpaceLocator](https://t.me/AirLocatorBot)

## Возможности
- Задание своего местоположения: адрес (геокодер [DaData](https://dadata.ru/)), координаты
  или геолокация Telegram.
- Поиск воздушных судов в заданном радиусе (100–500 км): радиус вводится числом или выбирается
  кнопкой-пресетом.
- Источники данных: [AirLabs](https://airlabs.co/); если AirLabs недоступен, бот автоматически
  переключается на [OpenSky Network](https://opensky-network.org/) и сообщает об этом.
  Данные из двух источников никогда не смешиваются.
- Фильтры по высоте, типу и принадлежности (стране) на inline-кнопках. Фильтры не удаляют данные:
  их можно свободно комбинировать, менять и сбрасывать без повторного запроса к API.
- Список найденных судов с нумерацией и карта с теми же номерами.
- «Повторить последний поиск» — поиск по сохранённым местоположению и радиусу без повторного ввода.
- «Подробно о воздушном судне» — выбор конкретного борта, фото с
  [planespotters.net](https://www.planespotters.net/) (если есть) и ссылка на
  [SKYbrary](https://skybrary.aero/).
- История последних запросов пользователя.

> У OpenSky нет информации о типе воздушного судна, поэтому для таких бортов тип не указывается
> и фильтр по типу их не затрагивает. Высота из OpenSky пересчитывается из метров в футы,
> как в AirLabs.

## Используемые технологии
- Python 3.12.
- [aiogram 3](https://docs.aiogram.dev/) — асинхронный Telegram-фреймворк (Router/FSM).
- [SQLAlchemy 2.0](https://www.sqlalchemy.org/) (async) + [Alembic](https://alembic.sqlalchemy.org/) — ORM и миграции, SQLite через `aiosqlite`.
- [httpx](https://www.python-httpx.org/) — асинхронные запросы к AirLabs, OpenSky, planespotters и DaData.
- [staticmap](https://github.com/komoot/staticmap) + Pillow — карта по тайлам OpenStreetMap
  (без GDAL/GEOS-зависимостей).
- [loguru](https://github.com/Delgan/loguru) — логирование, [pydantic-settings](https://docs.pydantic.dev/latest/concepts/pydantic_settings/) — конфигурация.
- [uv](https://docs.astral.sh/uv/) — зависимости и виртуальное окружение; pytest, respx, ruff — тесты и линт.

## Установка и запуск

### Переменные окружения (`.env`)
Создайте файл `.env` по образцу `.env.template`:

- `BOT_TOKEN` — токен Telegram ([BotFather](https://t.me/botfather)).
- `AIR_LABS_API_KEY` — API-ключ [AirLabs](https://airlabs.co/).
- `DADATA_TOKEN` — токен [DaData](https://dadata.ru/) (геокодер).
- `DADATA_SECRET_KEY` — секретный ключ [DaData](https://dadata.ru/) (геокодер).

OpenSky и planespotters работают без ключей. Необязательная переменная `DATABASE_URL`
(по умолчанию `sqlite+aiosqlite:///./data/bot.db`).

### Локально (uv)
```sh
uv sync
mkdir -p data
uv run alembic upgrade head
uv run python -m bot
```

### Docker
```sh
docker compose up --build -d
```
Миграции (`alembic upgrade head`) применяются автоматически при старте контейнера
(`docker/entrypoint.sh`). База данных сохраняется в `./data` на хосте.

### Тесты и линт
```sh
uv run pytest -q
uv run ruff check .
```

## Интерфейс пользователя

### Команды
| Команда    | Описание                                                                           |
|:-----------|:-----------------------------------------------------------------------------------|
| `/start`   | Запуск бота                                                                        |
| `/cancel`  | Возвращение в главное меню                                                         |
| `/help`    | Справка по командам                                                                |
| `/history` | Последние 50 запросов пользователя (константа `HISTORY_LIMIT` в `bot/constants.py`) |

### Главное меню
| Кнопка                              | Описание                                                                |
|:------------------------------------|:------------------------------------------------------------------------|
| `Изменить местоположение`           | Адрес, координаты или геолокация                                        |
| `Получить данные о воздушных судах` | Новый поиск: радиус числом или пресетом (100/200/300/500 км)            |
| `Повторить последний поиск`         | Поиск с сохранённым радиусом и местоположением                          |
| `Отрисовать полученные данные`      | Карта всех найденных судов                                              |
| `Подробно о воздушном судне`        | Выбор борта из списка: данные, фото, ссылка на SKYbrary                 |

### Меню после поиска (inline-кнопки)
Фильтры хранятся отдельно от найденных данных и применяются только при просмотре.

| Кнопка              | Описание                                                            |
|:--------------------|:--------------------------------------------------------------------|
| `Высота`            | Диапазон высоты (диапазоны считаются по фактическим данным поиска)  |
| `Тип`               | Один или несколько типов судна                                      |
| `Принадлежность`    | Одна или несколько стран                                            |
| `Показать список`   | Нумерованный список судов с учётом фильтров                         |
| `Показать на карте` | Карта с номерами судов с учётом фильтров                            |
| `Сбросить фильтры`  | Сброс всех критериев                                                |
| `Готово`            | Завершение поиска, возврат в главное меню                           |

### Меню местоположения
| Кнопка                          | Описание                                                    |
|:--------------------------------|:------------------------------------------------------------|
| `Ввести адрес`                  | Адрес → координаты через [DaData](https://dadata.ru/)       |
| `Ввести координаты`             | Ручной ввод координат                                       |
| `Отправить свое местоположение` | Геолокация Telegram                                         |

## Структура проекта
```
bot/
  handlers/     # хендлеры aiogram (start, set_location, get_aircraft, draw, aircraft_info, ...)
  keyboards/    # reply- и inline-клавиатуры
  services/     # клиенты AirLabs, OpenSky, planespotters, DaData; геоматематика; отрисовка карты
  db/           # модели SQLAlchemy и репозитории
  states/       # FSM-состояния
migrations/     # миграции Alembic
tests/          # pytest (хендлеры, репозитории, сервисы)
```
